# Infinity Books

Infinity Books is a React-based online book library that allows users to browse, search, and interact with a collection of books. Users can read books, like their favorites, bookmark books, and switch between light and dark themes.

## Features

- Browse available books
- Search books
- Like books
- Add books to favorites
- Bookmark books
- Read books using an integrated PDF reader
- Light and dark mode support
- Saves user actions using localStorage
- Displays the number of liked, favorite, and bookmarked books
